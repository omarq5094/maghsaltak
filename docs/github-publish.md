# النشر عبر GitHub وVercel

1. يحفظ أمر `git commit` التغييرات كسجل واضح داخل المستودع، ثم يرسل `git push` هذه السجلات إلى مستودع GitHub المرتبط.
2. يحفظ GitHub الكود وتاريخ التعديلات، ويمكن الرجوع إلى الإصدارات السابقة عند الحاجة.
3. بعد ربط مستودع GitHub بمشروع Vercel مرة واحدة، ينشئ Vercel معاينة تلقائية عند دفع تغييرات جديدة إلى GitHub، ويعطي رابطًا لمراجعتها.
