# مغسلتك — v3

التاريخ: 2026-10-11. هذه النسخة تعيد تنظيم النظام كمشروع واحد موحّد، دون بناء واجهات أو تشغيل قاعدة بيانات.

## المسارات والبوابات

| المسار | البوابة | ملفاتها |
| --- | --- | --- |
| `/` | العميل | `portals/customer/` |
| `/kiosk` | الكشك | `portals/kiosk/` |
| `/admin` | الإدارة | `portals/admin/` |

يُنشر المشروع كنظام واحد، ويحدد موجّه المسارات البوابة المطلوبة داخل النشر نفسه عند اختيار التقنية لاحقًا. لا تظهر روابط `/kiosk` أو `/admin` في تنقل بوابة العميل. وعند تنفيذ تسجيل الدخول لاحقًا، يجب أن يتحقق الخادم من صلاحية الوصول إلى هذين المسارين؛ إخفاء الروابط وحده لا يمثل حماية.

## الهيكل المشترك

- `portals/`: ملفات البوابات الثلاث، مفصولة حسب نطاق كل بوابة.
- `shared/api/`: عقد وطبقة API المشتركة مستقبلًا.
- `shared/logic/`: منطق النظام المشترك مستقبلًا.
- `shared/schema.sql`: مخطط البيانات المشترك المحفوظ من `v2`.
- `shared/order-statuses.json`: حالات الطلب المشتركة المحفوظة من `v2`.
- `shared/order-status-transitions.json`: انتقالات الحالات حسب طريقة الاستلام، محفوظة من `v2`.

تتواصل البوابات الثلاث مع API واحدة، وتتولى هذه الـAPI وحدها الوصول إلى قاعدة بيانات واحدة وتطبيق الصلاحيات وقواعد العمل المشتركة. لا تتصل أي بوابة بقاعدة البيانات مباشرة.

لم تُحدد تقنية التطبيق أو المسارات البرمجية أو نظام تسجيل الدخول بعد، ولم يُنشأ اتصال فعلي بقاعدة بيانات أو دفع أو رسائل في هذه النسخة.
