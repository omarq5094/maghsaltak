# مغسلتك — v2

التاريخ: 2026-10-11. هذه النسخة تضع هيكل النظام فقط.

## المشاريع

- `admin-web/`: واجهة الإدارة للطلبات والأسعار والخدمات والمندوبين والتقارير.
- `kiosk-web/`: واجهة الكشك لتسجيل القطع والخدمات، مع خيار المستعجل داخل اختيار القطعة والخدمة، ثم تأكيد العامل للاستلام.
- `customer-web/`: واجهة الجوال لإنشاء طلب الاستلام من المنزل وتتبع حالته.
- `shared/`: مخطط قاعدة البيانات وحالات الطلب المشتركة.

كل واجهة مشروع مستقل بملفاته الخاصة. لا تتصل الواجهات بقاعدة البيانات مباشرة. عند بناء التشغيل الفعلي، تتواصل الواجهات الثلاث عبر واجهة برمجة تطبيقات (API) مشتركة، ويتولى الخادم وحده قراءة قاعدة البيانات وكتابتها. يستخدم الخادم مخطط `shared/schema.sql` وحالات `shared/order-statuses.json` مرجعًا واحدًا، ويطبق الصلاحيات بحيث لا تصل واجهة العميل إلى وظائف الإدارة أو العامل.

لم يُنشأ خادم أو اتصال فعلي بقاعدة البيانات في هذه المرحلة. اختيار محرك قاعدة البيانات، آلية تسجيل الدخول، قواعد التسعير، ورسوم المستعجل تُحدد لاحقًا.
